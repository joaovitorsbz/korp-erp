Projeto Korp

Servico Go containerizado, atras de proxy reverso NGINX, com metricas Prometheus e dashboard Grafana.

Chamar GET /projeto-korp retorna JSON com nome e horario UTC atual

Como ver as metricas no Grafana

  • 1. Acesse http://localhost:3000 e entre com admin / admin.
  • 2. O datasource Prometheus e o dashboard http-server-projeto-korp ja vem provisionados automaticamente — nenhum clique manual necessario.
  • 3. O dashboard mostra: Disponibilidade (metrica up), Requisicoes por segundo, Total de requisicoes e Requisicoes por status.
  • 4. Para gerar trafego de teste: for i in {1..20}; do curl -s localhost/projeto-korp >/dev/null; done

Arquitetura

cliente -> nginx :80 -> http-server-projeto-korp :8080 (rede korp-net)
                 |
                 +-- prometheus :9090 (scrape /metrics)
                 +-- grafana    :3000 (datasource + dashboard provisionados)
